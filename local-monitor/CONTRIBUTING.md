# Contributing

Contributions are welcome.

1. Do not include real credentials, account names, task titles, local paths, IP addresses, databases, or screenshots with personal data.
2. Keep changes focused and add a reproducible test for bug fixes.
3. Run `python mobile/audit.py`, the Python regression tests, and an APK build before opening a pull request.
4. Describe any validation that still requires a physical Android device.

By contributing, you agree that your contribution is licensed under the MIT License.
