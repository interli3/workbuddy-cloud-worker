# WorkBuddy 工具集

非官方社区项目，与腾讯 / WorkBuddy 官方无隶属关系。请在遵守服务条款与当地法律的前提下使用。

本仓库包含**两块互相独立、可以分开使用**的东西。它们解决的是**不同场景**的问题：

| | 🖥️ **local-monitor** —— 看得清楚 | ☁️ **cloud-worker** —— 不用管 |
| :-- | :-- | :-- |
| **一句话** | 你电脑上的多账号看板 + 安卓 App + 用量统计 | 跑在云上的自动签到 / 猫猫旅行 / 成长任务 |
| **需要开电脑吗** | **要**（数据源在电脑本地） | **不要**（云端自己 24 小时跑） |
| **解决什么** | 余额、消耗、任务流水、账号健康度，一眼看清 | 每天该领的积分自动领掉，你不用动手 |
| **形态** | 本机 Web 面板 + 安卓 App + 桌面小组件 + Python 伴侣服务 | 一个常驻 Node 小服务（+ 可选云数据库） |
| **技术栈** | Node.js 18+ / Python 3.10+ / Java（安卓） | Node.js 18+，零外部依赖 |
| **怎么用** | 🔗 [local-monitor/README.md](local-monitor/README.md) | 🔗 [cloud-worker/README.md](cloud-worker/README.md) |

两者**可以只用其中一个，也可以一起用**，彼此不依赖。

---

## 怎么选

- **只想要「不用开电脑，自动把积分领了」** → 用 **`cloud-worker`**（把服务挂到云上，电脑关机照跑）。
- **想随时看到多个账号的余额 / 消耗 / 流水，手机上也能看** → 用 **`local-monitor`**（电脑上跑，手机连同一个局域网或走 MQTT 看）。
- **两个都要** → 一起用。注意两者都会用到 WorkBuddy 的登录令牌，请各自按各自的说明配置。

## 两块各自在做什么

### ☁️ `cloud-worker` —— 让"领积分"这件事彻底不用你操心

一个零依赖的 Node 单进程服务，启动后自己按间隔循环：

- **每日签到**（Buddy 加油站积分，幂等：已领不会重复请求）
- **猫猫旅行循环**（遍历所有猫：切换 → 查状态 → 到了就领奖 → 空闲就派出，跑完恢复你原来选中的那只）
- **成长计划任务**（自动接取 + 补缺口 + 领奖，覆盖 15 条常驻任务）
- **令牌自我续期**（access 快到期时自动用 refresh 换新）

它可以跑在你自己的电脑上，也可以**发布到一个单端口 HTTP 托管**上 —— 后者才是"电脑关机也照跑"的关键。

> ⚠️ 成长任务里「体验和平精英主题」默认跳过（换主题对客户端有真实副作用）。

### 🖥️ `local-monitor` —— 隐私优先的本地多账号工具

完全本地运行，凭证不出你电脑：

- **本机 Web 面板**：管理任意数量的 CN / Global 账号，汇总余额、套餐周期、今日 / 本月消耗、任务流水
- **安卓 App**：概览、账号、记录、健康度、风险提醒；含「DeepSeek 余额」独立页（手机直连官方余额接口，**电脑关机也能查**）
- **桌面小组件**：余额、签到、任务状态，Android 桌面一眼可见
- **自动签到**：Windows 计划任务 09:00 / 21:00 与登录后补签
- **连接方式**：局域网 HTTP 优先，外网可选 MQTT 会合点

## 共同的原则

- **本地优先 / 凭证不外流**：两块都**不把令牌写进代码或提交进仓库**；`config.json`、`credentials.json`、`config.local.json` 等一律被 `.gitignore` 排除。
- **不伪造成功**：过期数据会明确标记，能查不到就说查不到。
- **非官方**：接口与活动规则随时可能被官方调整，本项目不提供任何稳定性或合规性保证。
